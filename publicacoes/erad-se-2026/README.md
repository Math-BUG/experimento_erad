# ERAD-SE 2026 — Publicação e pôster

**Título:** Avaliação do Custo de Treinamento de IDS para IoT em Clusters CPU e GPU.

**Autores:** Matheus Antony Souza Pereira; Vitor Barbosa Souza; Daniel Louzada Fernandes.

Organização prevista:
- `artigo.pdf` — versão final publicada ou apresentada, após conferência;
- `fonte/` — fonte LaTeX correspondente à versão final, caso possa ser divulgada;
- `poster.pdf` — versão final do pôster utilizado na apresentação;
- `figuras/` — figuras selecionadas do artigo e do pôster.

Não publicar versões preliminares como se fossem as finais; registrar diferenças entre benchmarks CPU e GPU e entre implementações.

O código e os scripts de submissão permanecem na raiz do repositório e em `src/` e `scripts/`.
